# cdesign-starter v3

Treat this repository as neutral runtime infrastructure.

For a new site, do not start from a demo composition. Read the cdesign v3 INTENT, implement its DESIGN_GENOME and SIGNATURE_DECISION, and import only components whose behavior serves those decisions. Select and register project fonts rather than inheriting a starter pair.

For an existing cdesign site, read .cdesign/INTENT.md and .cdesign/FINGERPRINT.json, apply a delta, and preserve locks. Legacy Selected vibe data is only a hint.

Keep content truthful, motion accessible and device-aware, canvases performance-adaptive, and responsive states faithful to the same identity. Run lint, typecheck, build, audit:cdesign, visual QA, and independent or inline critique before handoff.
